JSON SYNTAX — every JSON file the project ships, written as a field skeleton

Generated by verification/population/alternatives/make_json_syntax.py from the files on
disk. Types are read off the data, not declared: integer means every sampled value is a
whole number, number means at least one is fractional, and a union prints as a union.

  !    present on every row sampled          ?  present on some rows
  null printed in the type when a key is present but its value is null
  *    the loader supplies a default when the key is absent (listed at the foot of the file)

==============================================================================
DEFAULTS THE LOADER SUPPLIES WHEN A KEY IS ABSENT (marked * above)
==============================================================================

  civHint                the pack id
  civId                  the string "neutral"
  confidence             the string "estimated" for places, "high" for events
  effect                 the string "note"
  end                    start + 1 for an event; Integer.MAX_VALUE for a trait or a border
  endYear                null (unbounded)
  from                   Integer.MIN_VALUE (always)
  fromYear               Integer.MIN_VALUE
  id                     the string "site" / "event" / "trait" / "border" / "unknown" depending on the level
  kind                   the string "event" / "box" / "settlement" depending on the level
  lat                    0.0 for a region with no centre, silently
  lon                    0.0 for a region with no centre, silently
  maxLat                 90
  maxLon                 180
  minLat                 -90
  minLon                 -180
  name                   the id (or the literal word event)
  occupiedEnd            Integer.MAX_VALUE (still there)
  occupiedStart          UNKNOWN (Integer.MIN_VALUE), never year 0
  population             0, and a zero row is discarded
  radiusKm               25.0 km for an event, 10 km for a region
  rank                   null; the urban window decides instead
  settlementCount        0, which disables aggregate apportionment
  source                 an empty string, which REJECTS the whole census row
  spawnDefaultRadiusKm   30 (not read by any code)
  spawnRadiusKm          30.0 km
  start                  Integer.MIN_VALUE for a trait or a border
  startYear              null (unbounded)
  toYear                 Integer.MAX_VALUE
  until                  Integer.MAX_VALUE (never ends)
  year                   0 in a census row
